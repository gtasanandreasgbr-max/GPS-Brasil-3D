
# GPS Brasil

Aplicativo de localização com mapa 2D.

## Arquivos
- index.html
- manifest.json
- sw.js
- README.md

## Como publicar

1. Entre no seu repositório do GitHub.
2. Substitua os arquivos antigos pelos novos.
3. Entre em Settings.
4. Abra Pages.
5. Selecione Deploy from a branch.
6. Escolha a branch principal.
7. Selecione a pasta / (root).
8. Salve.

## Recursos

- Mapa 2D claro.
- Ruas e avenidas identificadas.
- Ponto azul de localização.
- Círculo de precisão.
- Cone de direção, quando o aparelho oferece sensor.
- Acompanhamento durante a caminhada.
- Interface adaptada para celular.

## Atenção

O aplicativo precisa de HTTPS para acessar a localização.

Esta versão ainda depende da internet para carregar o mapa.
O GPS pode receber coordenadas sem internet, mas os mapas não
estão disponíveis offline nesta versão.
